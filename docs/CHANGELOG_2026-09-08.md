# Журнал изменений за 2026-09-08

## Обзор

Сегодня были внесены значительные улучшения в CRM-систему: добавлена полноценная поддержка калькуляции (состава работ) для заявок, страница калькуляции, а также модалка детального просмотра заявки с отображением всех данных и состава работ.

## Список коммитов

### 1. feat(schemas): add RequestItemIn and items field to RequestIn
**SHA:** `42dcbd4`  
**Файлы:** `backend/schemas.py`

**Изменения:**
- Добавлена схема `RequestItemIn` для валидации позиций состава работ:
  - `price_item_id` (int, optional)
  - `category_name` (str)
  - `name` (str)
  - `unit` (str, по умолчанию "шт")
  - `unit_price` (float)
  - `quantity` (int, по умолчанию 1)
- В схему `RequestIn` добавлено поле `items: List[RequestItemIn] = []`

**Зачем:** Позволяет создавать и редактировать заявки с составом работ через API.

---

### 2. feat(requests): save/edit calculation items and add GET /api/requests/{id}
**SHA:** `aebf2d6`  
**Файлы:** `backend/requests.py`, `backend/db.py`

**Изменения:**
- **GET /api/requests/{id}**: Новый эндпоинт для получения заявки с составом работ
  - Возвращает заявку с полем `items`, содержащим позиции калькуляции
  - Каждая позиция содержит snapshot-данные (название, категория, цена, единицы)
- **POST /api/requests**: Обновлена логика создания заявки
  - Сохранение позиций состава работ в таблицу `request_items`
  - Для каждой позиции сохраняются snapshot-данные из прайса
- **PUT /api/requests/{id}**: Обновлена логика редактирования заявки
  - Полное обновление состава работ: удаление старых позиций и создание новых
  - Сохранение актуальных snapshot-данных

**Зачем:** Бэкенд-поддержка для работы с составом работ в заявках.
