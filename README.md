# Master CRM v2.1

Master CRM — внутренняя CRM-система для управления заявками выездных мастеров с календарём выездов, прайс-листом, калькуляцией услуг, аналитикой и Telegram-интеграцией.

## Возможности

### Заявки
- Создание, просмотр, редактирование и удаление заявок
- Поля: клиент, дата и время выезда, адрес, телефон, источник, способ связи, статус, цена, ответственный и комментарий
- Статусы: Новая, Назначена, В работе, Завершена, Отменена
- Фильтры по статусу, мастеру, дате, источнику и способу связи
- Поиск по клиенту, адресу, телефону, комментарию и ответственному
- **Калькуляция / Состав работ**: добавление позиций из прайса с количеством и ценой
- **Детальный просмотр**: модалка с полной информацией о заявке и составом работ

### Калькуляция
- Отдельная страница `/calculation` для выбора позиций прайса
- Поиск и фильтрация по категориям
- Корзина выбранных позиций с изменением количества
- Итоговая сумма
- Быстрый переход к созданию заявки с переносом состава работ
- Интеграция с формой заявки: редактирование количества и цены на месте

### Календарь
- Представления: Месяц, Неделя и День
- Цветовые маркеры статусов заявок
- Синхронизация выбранного дня с фильтром и списком заявок
- Исправлено отображение дат в локальном часовом поясе: ячейки формируются без UTC-сдвига

### Прайс-лист
- Отдельная страница `/price` с категориями услуг и позициями
- Создание, редактирование и удаление категорий и позиций
- Поля позиции: название, цена, единица измерения и порядок отображения
- Обычные цены, диапазоны и текстовые значения: `1500`, `1500-4000`, `от 500`
- Категории сворачиваются; при открытии страницы они закрыты по умолчанию
- Адаптивное отображение на смартфоне: название, затем цена и единица измерения
- Экспорт прайса в CSV
- Администратор всегда может редактировать прайс; менеджер — при наличии права `can_edit_price`

### Роли и пользователи

| Роль | Возможности |
|---|---|
| Мастер | Работа с доступными заявками и календарём |
| Менеджер | Управление заявками, клиенты, аналитика, аудит; прайс при наличии права |
| Администратор | Полный доступ, включая пользователей, настройки и прайс |

### Клиенты, аналитика и аудит
- База клиентов на основе заявок и история обращений
- Экспорт клиентов в CSV
- Статистика по заявкам, статусам, источникам и выручке
- Рейтинг мастеров и активных клиентов
- Отчёты за произвольный период
- Аудит-лог изменений

### Интерфейс и интеграции
- Адаптивный mobile-first интерфейс
- Светлая и тёмная темы с сохранением выбора
- Модальные формы и общее меню разделов
- Отдельный Telegram-бот: `telegram_bot.py`

## Быстрый запуск

### Требования
- Python 3.10+
- SQLite3
- Git
- Nginx и systemd — для production-развёртывания

```bash
cd /opt
git clone https://github.com/VivaGushter/crm.git master-crm
cd master-crm
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
python app.py
```

Альтернативный запуск:

```bash
uvicorn app:app --host 0.0.0.0 --port 8000
```

## systemd и Nginx

```bash
sudo cp master-crm.service /etc/systemd/system/master-crm.service
sudo systemctl daemon-reload
sudo systemctl enable master-crm
sudo systemctl start master-crm
sudo systemctl status master-crm
```

Логи приложения:

```bash
sudo journalctl -u master-crm -f
```

Nginx:

```bash
sudo cp nginx-master-crm.conf /etc/nginx/sites-available/master-crm
sudo ln -s /etc/nginx/sites-available/master-crm /etc/nginx/sites-enabled/master-crm
sudo nginx -t
sudo systemctl reload nginx
```

## Telegram-бот

Создайте бота через `@BotFather`, сохраните токен вне репозитория и настройте параметры согласно `telegram_bot.py`. Запуск:

```bash
cd /opt/master-crm

```

## API

Все API-запросы используют HTTP Basic-аутентификацию.

| Метод | Endpoint | Назначение |
|---|---|---|
| GET | `/api/me` | Текущий пользователь и права |
| GET/POST | `/api/requests` | Список и создание заявок |
| GET | `/api/requests/{id}` | Получение заявки с составом работ |
| PUT/DELETE | `/api/requests/{id}` | Изменение и удаление заявки |
| GET/POST | `/api/users` | Просмотр и создание пользователей |
| PUT/DELETE | `/api/users/{user_id}` | Изменение и удаление пользователя |
| GET | `/api/prices` | Категории и позиции прайса |
| POST | `/api/prices/categories` | Создание категории прайса |
| PUT/DELETE | `/api/prices/categories/{id}` | Изменение или удаление категории |
| POST | `/api/prices/items` | Создание позиции прайса |
| PUT/DELETE | `/api/prices/items/{id}` | Изменение или удаление позиции |
| GET | `/api/prices/export` | CSV-экспорт прайса |
| GET | `/api/report` | Отчёт за период |
| GET | `/api/analytics` | Аналитика |
| GET | `/api/clients` | База клиентов |
| GET | `/api/clients/{name}` | Карточка клиента |
| GET | `/api/clients/export` | CSV-экспорт клиентов |
| GET | `/api/audit` | Аудит-лог |
| GET/PUT | `/api/me/settings` | Пользовательские настройки и тема |

## База данных и резервные копии

Приложение использует SQLite. Таблицы и миграции создаются при запуске через `backend/db.py`.

Основные сущности: пользователи, заявки, категории прайса, позиции прайса, состав работ заявок (`request_items`) и аудит-лог.

Перед обновлением production-сервера создавайте резервную копию БД:

```bash
cd /opt/master-crm
cp data/crm.db "data/crm.db.backup-$(date +%F-%H%M%S)"
```

При необходимости уточните путь к БД по `backend/config.py` и `backend/db.py`.

Публикация своих изменений:


## Безопасность

- API защищён HTTP Basic-аутентификацией
- Роли и проверки прав выполняются на стороне API
- Существенные операции фиксируются в аудит-логе
- Не храните пароли, токены и секреты в Git
- Используйте HTTPS, уникальные пароли и регулярные резервные копии
- Рекомендуется перейти на Argon2 или bcrypt для хранения паролей при дальнейшей доработке
