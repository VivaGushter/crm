# Master CRM v2.0

CRM-система для управления заявками мастеров с календарём выездов, прайс-листом, аналитикой и Telegram-интеграцией.

## Возможности

### Заявки
- Создание, редактирование и удаление заявок
- Статусы: Новая, Назначена, В работе, Завершена, Отменена
- Привязка к исполнителю
- Источник: Авито, Домовые чаты, Не указан
- Способ связи: Авито, Звонок, Telegram, Max

### Календарь
- Месяц, Неделя, День
- Исправлено отображение дат (MSK)

### Прайс-лист
- Категории и позиции
- Диапазоны цен (1000-3000)
- Сворачивание категорий
- Экспорт CSV

### Роли
- Мастер, Менеджер, Администратор

### Аналитика
- Отчёты, статистика, топ мастеров и клиентов

### Интерфейс
- Адаптивный, тёмная/светлая темы

## Структура

## Установка

```bash
cd /opt
git clone https://github.com/VivaGushter/crm.git
cd crm
pip install -r requirements.txt
python app.py
```

## API

- `/api/requests` — заявки
- `/api/prices` — прайс
- `/api/users` — пользователи
- `/api/analytics` — аналитика
- `/api/audit` — аудит
